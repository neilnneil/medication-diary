# 用藥小記

可放在 GitHub Pages 的手機優先用藥紀錄網頁。預設提供頭痛藥（21:00）、憂鬱藥（21:00）及補血藥（08:00），都可自行修改或刪除，也能新增藥品。時間只是示範值，請先依實際處方調整。

## 功能

- 自訂藥名、每日或指定星期、服用時間
- 今日清單、已過預定時間但尚未記錄的提示
- 記錄服用、復原誤觸、查看最近 20 筆服用紀錄
- 資料存於這台裝置的瀏覽器，支援 JSON 匯出與匯入備份
- 支援離線開啟（首次載入後）及加入手機主畫面

## 資料保存

藥品設定與服用紀錄存於網站的 `localStorage`，與提供離線頁面的 service worker 快取不同。`localStorage` 沒有程式設定的到期日，但清除網站資料、刪除主畫面網頁 App、瀏覽器或系統清理資料時都可能消失。Safari 的追蹤防護對一般網站有「連續 7 天使用 Safari、卻未與該網站互動」的腳本儲存清理規則；加入主畫面的第一方網頁 App 不受該 7 天規則限制。仍建議定期使用「管理藥品 → 匯出備份」。

資料以網站來源區分。從本機預覽網址改為 GitHub Pages 網址後，紀錄不會自動搬過去；若已在本機建立紀錄，先匯出 JSON，再於正式網址匯入。不同手機之間也需要手動備份與匯入。

## 本機預覽

請用本機 HTTP 伺服器開啟，避免 `file://` 對 ES modules 與 service worker 的限制。安裝 Node.js 後，在此資料夾執行：

```sh
node dev-server.cjs
```

然後開啟 `http://localhost:8765`。

## 發布到 GitHub Pages

1. 將此資料夾的檔案推送至 GitHub 儲存庫預設分支。
2. 在儲存庫 **Settings → Pages → Build and deployment**，選 **Deploy from a branch**、預設分支與 **/(root)**，儲存。
3. 用 Pages 提供的 `https://使用者名稱.github.io/儲存庫名稱/` 網址在手機開啟。iPhone 可從 Safari 分享選單選「加入主畫面」。

不要把匯出的備份 JSON 放進公開儲存庫；它含有個人用藥資料。

## iPhone 通知的技術界線

本版本只有**開啟網頁時**的逾時提醒，關閉網頁後不會發系統通知。iOS 16.4 以後，加入主畫面的網頁可在使用者授權後接收 Web Push；實作還需要後端儲存推播訂閱、定時檢查服藥狀態並發送通知。GitHub Pages 只託管靜態內容，因此無法單獨完成這一段。若要可靠的 iPhone 提醒，下一階段可增加後端與帳號同步，或製作原生 iOS App 使用本機通知。

本工具只記錄使用者輸入，不判定是否該補服或變更劑量。藥品異動請依醫囑。
